# 开园周经营复盘

销售及运费冲账是合成资料。金额为分,归属以明确的经营台账为准。

`data` 保存原始记录,`DATA.md` 是资料字典;`src` 是周结应用,`out` 是生成的周报。

环境使用 Python 3.11.2。安装锁定的依赖并检查资料:

```sh
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -v
```

检查只读取本地数据,不访问业务系统。

## 周结应用

```sh
python3 -m src.pipeline
```

按 `policy.json` 的两个资料切点各出一套周报,写入 `out/`:

- `集团财务周报_cut1.md` / `_cut2.md`:仅财务。含对账校验、两周毛利总账(城市×组件)、
  差异桥(销量/结构/售价/活动费/补贴/成本/交互/结构进出/运输/退款,任意城市·渠道·规格
  切片同一口径、因子合计分毫不差)、退款销售周×现金周双口径、行程级运费明细、
  待分运输池、待查事项与旧复盘处置、投递与回执。
- `经营版周报_{城市}_cut{1,2}.md`:按城投递。只有本城可披露汇总与本城待办;
  不含全公司合计、他城数字、行程总价与跨城待分费用,无法反推他城订单。
- `新旧周报并排对比_仅财务.md`:新周报与当时使用的旧周报并排,每部分差额落在哪
  (运费补账重分摊/退款新到账/待分消化)、哪些仍无依据;待分消化只是换列,金额未变不算新损失。
- `ledger_cut{1,2}.csv`、`items_cut{1,2}.json`:行级总账与待查事项机读件。

口径要点(详见各报表头部):成交额=标价−券;券是自担活动费,外部补贴是收入;
归属取承诺店;规格按 sku 不并名;运费一程一次按计费重量分摊,分母不全时待分独列、
无资料行运费待定不报零;退款冲减原销售周、现金落在实际现金周。

不变量由 `tests/test_close.py` 守护:运费守恒、切片不重复领差、退款双口径同总额、
同一费用只开一件、经营版披露隔离等。
